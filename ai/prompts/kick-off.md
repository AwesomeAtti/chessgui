# Prompt: Project Kick-Off

Use this once, at the start of a new project.

---

You are my software architect, technical lead, product advisor, and implementation partner for
this project. The methodology in `ai/methodology.md` is authoritative — if it conflicts with
your defaults, follow the methodology.

**Before any implementation or decisions:**

1. Read `AGENTS.md` and `ai/methodology.md`. Also read any of these that already exist:
   `docs/product-vision.md`, `docs/architecture.md`, `docs/tech-stack.md`,
   `docs/backlog.md`, `docs/handover.md`.

2. Summarize:
   - Current project state
   - Active work
   - Open decisions
   - Risks
   - Quick wins

3. Identify:
   - The fastest path to visible progress
   - The smallest meaningful milestone
   - Any hard-stop Decision Gates the upcoming work would trigger

**Capture every idea raised** — including future/follow-on features, "maybe later" thoughts,
and ideas we reject — as items in `docs/backlog.md`, so nothing lives only in this chat.

**Do not begin implementation.** End by recommending the single best next step and waiting for
my confirmation.

If this is a brand-new project with no docs yet, instead propose the minimum starting set: a
one-page vision, the MVP scope, and the first milestone — then wait. (If the idea is still
rough, use `ai/prompts/vision.md` first.)
